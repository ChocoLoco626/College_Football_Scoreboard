# College Sports Live Scoreboard

A Streamlit college-sports scoreboard powered by ESPN's public scoreboard feeds.

## Included

- Football: FBS + FCS
- Men's and women's basketball
- Baseball and softball
- Men's and women's hockey
- Men's and women's soccer
- Men's and women's lacrosse
- Men's and women's volleyball
- Field hockey
- Women's gymnastics
- Men's and women's tennis
- Wrestling
- Men's and women's golf
- Swimming & diving
- Track & field
- Cross country
- Rowing
- Water polo
- My Teams dashboard
- Favorite-team highlighting
- Team logos
- Live status and game clock/period when supplied by ESPN
- TV/broadcast information when supplied by ESPN
- All games sorted by score closeness, with live games first
- Close-game threshold
- Automatic refresh

Some ESPN sports are seasonal, so a sport can legitimately show no games when it is out of season.

## Streamlit Community Cloud

1. Put this project in a GitHub repository.
2. Go to https://share.streamlit.io/
3. Create an app using `app.py` as the main file.
4. Deploy.

The project includes the deployment files from the earlier football version as well.
